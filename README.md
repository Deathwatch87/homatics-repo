# Homatics Kodi repository

Kodi add-on repository for my Homatics boxes: Box Tuner, Patch Guard and the Nimbus Homatics skin.

Install on a box (once): Kodi > Add-ons > Install from zip file > `repository.homatics-1.0.0.zip`
(download: https://raw.githubusercontent.com/Deathwatch87/homatics-repo/main/repository.homatics-1.0.0.zip).

Files are generated by `build_repo.py` - don't edit `addons.xml` by hand.
